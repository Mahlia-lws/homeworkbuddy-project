Homework Buddy!

Homework Buddy is a manager/planner app that allows you to keep track of and add your homework.

How to run the app:
Type in "python main.py" into the terminal to get this:

Welcome to the Homework Buddy!
1. Show homework 
2. Add homework
3. Show all homework
4. Exit
Choose an option:

The things you can do in the app is:
Show homework
Add homework
Show all homework
Exit

All the files are:
main.py – Main program
Homework.py – Homework
assignments.py – Assignments
projects.py – Projects
planner.py – Planner
